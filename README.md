# Amazon Web Scraping Project

A Python project that extracts key product information from an Amazon listing and automatically saves the collected data to a CSV file for use in Microsoft Excel.

## Overview

This project uses web scraping techniques to collect product information from an Amazon listing. The extracted data is organized and exported into a CSV file, making it easier to review and analyze using spreadsheet software.

## Tools & Technologies

- Python
- Jupyter Notebook
- Web Scraping
- CSV
- Microsoft Excel

## Features

- Extracts key product information from an Amazon listing.
- Automates the collection of product data.
- Organizes extracted information into a structured format.
- Automatically exports collected data to a CSV file.
- Creates an Excel-compatible file for further analysis.

## Files

- `Amazon Web Scraper Project.ipynb` - Jupyter Notebook containing the web scraping code.

## Purpose

To practice Python automation and web scraping while learning how to collect, structure, and export data from an online source.
